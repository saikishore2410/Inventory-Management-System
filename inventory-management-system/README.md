# Inventory Management System

Java 21 + JavaFX + Maven + SQLite desktop inventory application.

## Features
- Item CRUD
- Vendor CRUD
- Stock In / Stock Out
- Prevents negative stock
- Low-stock indicator
- SQLite persistence
- Transaction-safe stock adjustments
- JUnit 5 automated tests

## Run
```bash
cd inventory-management-system
mvn clean test
mvn javafx:run
```
